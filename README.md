# 🚀 Maxis 3D Product Catalog

A modern **3D Product Catalog Platform** for showcasing products through an immersive and interactive web experience.

Built for industrial companies, manufacturers, and distributors, Maxis allows users to explore products in real-time 3D with a modern interface, fast loading, and a powerful management system.

---

## 🎮 Interactive 3D Viewer

- Real-time 3D rendering
- Rotate, Zoom & Pan
- High-quality textures
